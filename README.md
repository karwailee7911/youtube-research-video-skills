# YouTube Research Video Skills

两套面向中文研究型 YouTube 长视频的 Codex skills，把工作分成两段：先判断选题值不值得做，再把通过的选题制作成可发布的视频。

它们适用于医学、经济、科技、文学、历史等需要查原始资料、核对证据和解释边界的内容。资料来源不限于古籍，也包括官方数据、公司文件、技术文档、学术论文，以及经过校勘的文学与历史文献版本。

## 这套流程解决什么

研究型视频容易在三个地方出错：选题缺少搜索需求，口播中的判断超出证据，字幕和画面没有跟随最终语音。

这两个 skills 为这些环节设置检查点：

- 写稿前检查搜索需求、竞争内容和证据可行性
- 保存原始资料，区分事实、推论和解释
- 锁定口播稿后再生成视觉素材和语音
- 用最终音频确定字幕、画面和章节时间
- 直接编辑剪映草稿文件，不使用桌面或 GUI 自动化
- 写入前备份，写入后解密回读并核对轨道
- 输出封面、标题、简介、章节、来源和标签

## 两个 skills

| Skill | 负责什么 | 主要输出 |
|---|---|---|
| [`youtube-topic-search-gate`](skills/youtube-topic-search-gate/) | 调查搜索需求、竞品、差异化和证据强度 | `GO`、`REWORK` 或 `PARK` 选题简报 |
| [`youtube-research-video-production`](skills/youtube-research-video-production/) | 完成研究、口播、视觉、音频对齐、剪映草稿、封面和发布资料 | 一套可检查的长视频项目文件 |

第二个 skill 只接收通过选题闸门的主题。上游口播发生变化时，它会判定下游字幕、画面和章节时间失效。

## 工作流程

```text
搜索需求与竞品
        ↓
选题闸门：GO / REWORK / PARK
        ↓
原始资料与证据档案
        ↓
锁定口播稿
        ↓
原页、图表、示意图和长图
        ↓
最终语音
        ↓
字幕声学对齐与画面时间轴
        ↓
剪映草稿直写与回读验证
        ↓
封面和 YouTube 发布资料
```

## 支持的内容类型

### 医学与健康

优先查临床指南、系统综述和权威机构资料。流程要求区分症状与诊断、急性治疗与预防、专业治疗与居家操作，并保留安全边界。

示例：`头痛、偏头痛怎么缓解？古籍记载与现代指南怎样区分危险信号？`

### 经济与商业

记录数据口径、统计期、单位、修订和比较基准。流程要求区分名义与实际、存量与流量、相关与因果。

示例：`降息一定会推高房价吗？比较过去三轮数据。`

### 科技与科学

核对官方文档、版本、源代码、论文和可复现实验。基准测试必须说明硬件、数据集、指标和运行条件。

示例：`这个 AI 模型真能替代搜索吗？按官方条件重新测试。`

### 文学、哲学与历史

标明作品版本、页码、译者、文本异文和解释分歧。生成的历史场景必须标注为插图或复原示意。

示例：`《红楼梦》真在这里暗示了结局吗？回到脂批原文。`

## 稿件形式

制作 skill 支持单人口播、双人问答和多角色稿件。它不会为了套模板而增加第二个说话者。

- 单人稿使用普通字幕轨
- 多角色稿可以输出角色时间清单
- 剪映原生字幕可按角色设置颜色
- 角色标签和 `[pause]`、`[emphasis]` 等表演标签不会进入字幕正文

## 字幕与剪映

最终音频是唯一时间基准。字幕脚本会检查整体相似度、双向锚点覆盖率、最长未匹配文本和最长无锚点音频跨度。音频与稿件版本不一致时，脚本会停止生成。

剪映流程只修改草稿文件：

- 不启动、点击或重启剪映
- 写入前核对草稿目录和 `draft_id`
- 检查锁定状态和写入期间的文件变化
- 在草稿目录外保存备份
- 保留 `.bak` 和小型 `template.tmp`
- 写入后解密回读，核对轨道、时长、素材路径和文件哈希

剪映字幕注入脚本需要用户提供已验证的本地草稿加解密工具。

## 安装

把两个目录复制到 `~/.codex/skills/`：

```bash
cp -R skills/youtube-topic-search-gate ~/.codex/skills/
cp -R skills/youtube-research-video-production ~/.codex/skills/
```

重新开始一个 Codex 任务后即可触发。

## 使用示例

```text
使用 $youtube-topic-search-gate，判断“降息一定会推高房价吗”值不值得做成一期中文 YouTube 长视频。
```

```text
使用 $youtube-research-video-production，把这份已经通过的选题简报制作成完整长视频项目。
```

```text
skills/
├── youtube-topic-search-gate/
│   ├── SKILL.md
│   ├── agents/
│   └── references/
└── youtube-research-video-production/
    ├── SKILL.md
    ├── agents/
    ├── references/
```

仓库只保存可复用的流程、参考规则和脚本，不包含用户视频、语音、剪映草稿、付费资料或原始扫描件。
